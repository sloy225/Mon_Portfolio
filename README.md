## 🛠️ Stack Technique

- **Framework :** React 18 + Vite 5 + TypeScript
- **Styling :** Tailwind CSS v3 avec design system étendu
- **Icônes :** `lucide-react`
- **3D & Canvas :** HTML5 Canvas personnalisé avec projection 3D en perspective et calcul matriciel
- **Build & Bundle :** Vite
